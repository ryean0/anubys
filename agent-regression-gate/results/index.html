Model ids are recorded at verdicts.overall.model_ids for the baseline and the candidate. baseline_pool_model_id names the pinned pool. run_kind is screening, baseline, aa, or gate. Screening, baseline, and aa share one model id across both arms. A gate run may use a different candidate id, and its baseline id must equal baseline_pool_model_id. The bundled diagnostics include example.clean.v1 (family example.clean) and example.broken.v1 (family example.broken).
