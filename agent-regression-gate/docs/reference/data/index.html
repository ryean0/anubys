    Where results go today

    Nothing uploads results yet. Today harness run writes run_summary.json on the runner. The results file on this site is an Example. OIDC roles and an artifacts bucket were deployed on October 9 to the dev AWS account. CI does not use them yet.

    Data stays in your cloud Planned

    Data stays in your cloud is Planned, and post-MVP. It is not how the run is stored today. Spend governance is Built. Keyless CI (OIDC): roles deployed, CI wiring in progress. The reproducible audit trail is in progress.

    Bring-your-own bucket Planned

    Bring-your-own bucket is Planned. It is post-MVP. Nothing uploads results yet. A bucket in your account is the later step.
