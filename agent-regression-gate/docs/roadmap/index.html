    Roadmap

    Three labels: Built, Next, and Planned. Dates are targets and can move.

    On this page

    1. Built
    2. Next
    3. Planned

    Built

    Built

    Rollout runner

    harness run, live and replay.

    Built

    Results schema 2.1.0 checker

    The site reads schema 2.1.0, and still reads 1 and 2.0.0.

    Built

    Gemini adapter

    One adapter and an allowlist entry for a pinned Gemini Flash-Lite model id (lives in config/allowed_models.txt and is passed with --model). Gemini is the only provider today.

    Built

    Cassette replay

    Keyed by a hash of each model request. Needs your own --record first. No sample recording ships. A replay is Example $0.

    Built

    Monthly spend check

    The Example $38 check stops new live rollouts once logged spend this UTC month reaches the cap. A run already in progress can finish, so the month can overshoot slightly.

    Built

    Per-user spend log

    Outside a checkout, live runs use one ~/.anubys/spend_log.jsonl per user per machine, with no override, so the monthly check cannot be split across folders.

    Built

    Run summary schema

    run_summary.json has a published schema, version 1.1.0, which adds model_version. This site still reads 1.0.0 files. Dollar amounts are decimal strings.

    Built

    Model version check

    Before the first paid call, a live run reads the model version from Gemini and refuses the run when it differs from the pinned version in config/model_versions.txt. Replay and a dry run skip that call.

    Built

    AWS dev account

    Terraform for an artifact bucket and keyless GitHub OIDC roles. Applied on October 9, 2026 to a personal dev AWS account. CI does not use those roles yet.
