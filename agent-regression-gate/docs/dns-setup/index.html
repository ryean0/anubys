    DNS setup

    anubys.dev is hosted on GitHub Pages. Squarespace only provides DNS. There is no Squarespace site plan.

    How the name points

    The site is the GitHub Pages site for ryean0/anubys. Squarespace holds the domain and publishes the DNS records. It does not serve the pages. A Squarespace site plan is not part of this setup.

    The path

    A request takes three steps. Squarespace answers the name. GitHub Pages serves the site.

    Records

    Add these in Squarespace DNS, after the default records in the next section are gone. The host @ is the bare domain, anubys.dev.

    Remove the Squarespace defaults

    Remove the Squarespace default records before you rely on the table above. Squarespace adds them for its parking page, or for a Squarespace website. If a default address stays beside the GitHub addresses, a lookup can return either one. Visitors then randomly hit the parking page or the site.

    Nameservers and DNSSEC

    Leave Domain Nameservers untouched. Leave DNSSEC untouched. Squarespace stays the DNS host. This page only replaces records inside that DNS. It does not move the domain to other nameservers.

    HTTPS on .dev

    .dev requires HTTPS. Browsers will not load the name over plain HTTP, so the site loads only after GitHub issues the certificate. That can take up to 24 hours. When the certificate is in place, tick Enforce HTTPS in the GitHub Pages settings for anubys.dev.

    Check the name

    From a machine with dig and curl:

    shell

    dig anubys.dev +short
dig www.anubys.dev CNAME +short
curl -I https://anubys.dev

    dig anubys.dev +short should list the four GitHub Pages IPv4 addresses. A resolver that answers with IPv6 lists the four AAAA addresses as well.

    dig www.anubys.dev CNAME +short should print ryean0.github.io.

    curl -I https://anubys.dev should return response headers once the certificate exists. Before that, it fails because .dev requires HTTPS, not because the DNS records are missing.
