    18 October 2026

    • Copy now matches harness main. harness run is live, replay, and dry run. It writes run_summary.json, not a verdict.
    • Cassette replay is Built. The Gemini adapter is Built. This site reads results schema 2.1.0, and still reads 1 and 2.0.0.
    • The monthly spend check stops new live rollouts at Example $38. A run already in progress can finish.
    • Private beta. MIT license planned. Not on PyPI yet. PyPI v0.1 is planned for November 16 to 20.

    16 October 2026

    • The bundled results sample matches harness schema 2.1.0. Model ids are recorded at verdicts.overall.model_ids and baseline_pool_model_id. Diagnostics include example.clean.v1 (family example.clean) and example.broken.v1 (family example.broken).
    • The results panel reads a run summary from a separate example file, schema_version 1.0.0. That file is not a field of results.json. It shows planned rollouts, completed rollouts, infrastructure misses, cached input tokens, total cost, and rollout duration p50 and max.
    • schema/step.schema.json matches the harness Step contract. thinking_tokens and cached_tokens are optional and may be null.

    15 October 2026

    • The landing page has a Zero latency in production section. More details opens the performance page.
    • Anubys runs as a CI check when a pull request opens and adds 0 ms to production model responses.
    • Example efficiency figures render from data/timing.sample.json. Measured numbers coming from Oct cost runs.
    • Cassette replay is labeled Landing with harness #14. It is not merged yet. Integrations and spend call it In review.
    • The model id is not final. Pages name a pinned Gemini Flash-Lite model id (exact version set in suite config).
    • The install guide is at docs/install/. It is labeled beta testing. Offline checks use the harness README commands. A full local gate stays Coming soon.

    13 October 2026

    • Docs for the introduction, the quickstart, concepts, guides, and reference.
    • The landing page gained a Why Anubys comparison and an enterprise strip.
    • The roadmap is labeled Built, Next, and Planned.
    • Data stays in your cloud is Planned, because results go to an S3 bucket the team controls. Bring-your-own bucket is post-MVP.
