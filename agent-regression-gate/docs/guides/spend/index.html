    Spend governance

    A monthly spend check, a cost on every call, and a replay at Example $0. The example check is Example $38.

    On this page

    1. Monthly spend check
    2. Cost per call
    3. Replays

    Monthly spend check Built

    The Example $38 monthly spend check stops new live rollouts once logged spend this UTC month reaches Example $38. A run already in progress can finish, so the month can overshoot slightly.

    The check is Built. Example $38 is the example, not a price for every install. The real knob is scripts/check_monthly_spend.py --threshold (default 38) or MONTHLY_SPEND_CAP_USD.

    shell

    python scripts/check_monthly_spend.py --threshold 38

    Cost per call

    Each call records its cost. That cost sits with the outcome. It is not a suite status.

    Showing cost per verdict on the check is Next, by October 29.

    Replays Built

    A replay is Example $0. The call is not billed again.

    Cassette replay is Built. The cassette key is a hash of each model request (cassette.py request_key is sha256). You need your own --record first. No sample recording ships.
