Untouched.

Orange marks the Anubys CI path.

Anubys never sits in the live request path. It runs as a CI check when a PR opens, so it adds 0 ms to production model responses. The cost is time on the PR check.

Built today

What keeps the check from lingering.

  • Wall-clock and max_steps caps

    A stuck agent can't hang the check.

  • Monthly spend check

    The Example $38 check stops new live rollouts. A run already in progress can finish.

  • Cassette replay Built

    Re-runs reuse recorded model calls. No API waits. No spend. The key is a hash of each model request. You record with --record first. No sample recording ships.

  • No servers or proxies

    Runs on GitHub's runners, then exits.

  • Pinned model ids

    Direct provider calls. No extra hop.

Tradeoff

Rollouts per arm.

Rollouts per arm is the overhead knob. More rollouts catch smaller drops, a smaller MDE, and a longer check.

Fewer rollouts More rollouts

Fewer rollouts can miss a smaller drop. More rollouts catch that drop and hold the pull request longer.
